# Thư mục Tài nguyên Giao diện (Assets) - UDM08 Chat App

Thư mục này chứa toàn bộ các tài nguyên hình ảnh, biểu tượng (icon) và avatar mẫu sử dụng trong Client của ứng dụng Chat.

## 📁 Danh sách tệp tin

| Tên tệp tin | Kích thước | Định dạng | Mô tả công dụng |
| :--- | :--- | :--- | :--- |
| `app_icon.png` | 704 x 406 | PNG | Logo / biểu tượng chính của ứng dụng |
| `default_avatar.png` | 352 x 350 | PNG | Avatar mặc định khi người dùng chưa đặt ảnh |
| `emoji_icon.png` | 48 x 48 | PNG (Alpha) | Biểu tượng nút bấm mở Emoji Picker |
| `send_icon.png` | 48 x 48 | PNG (Alpha) | Biểu tượng nút gửi tin nhắn (Send) |
| `attach_icon.png` | 48 x 48 | PNG (Alpha) | Biểu tượng đính kèm tệp / file |
| `avatar_user1.png` | 128 x 128 | PNG (Alpha) | Avatar mẫu thành viên (GB - Gia Bảo) |
| `avatar_user2.png` | 128 x 128 | PNG (Alpha) | Avatar mẫu thành viên (TT - Thuận Trí) |
| `avatar_user3.png` | 128 x 128 | PNG (Alpha) | Avatar mẫu thành viên (BN - Gia Bân) |
| `avatar_user4.png` | 128 x 128 | PNG (Alpha) | Avatar mẫu thành viên (TM - Bích Trâm) |

## 🎨 Quy chuẩn thiết kế (Guidelines)
- Tất cả các icon được tối ưu cho giao diện Dark Theme (`#18191a` / `#242526`).
- Các biểu tượng và avatar đều có nền trong suốt (RGBA channel) và hỗ trợ bo tròn với `CircularAvatar`.
- Khi bổ sung hình ảnh mới, khuyến nghị định dạng PNG hoặc SVG có độ phân giải tối thiểu 48x48 cho icon và 128x128 cho avatar.
